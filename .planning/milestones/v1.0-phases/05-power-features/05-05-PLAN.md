Add dynamic shell completions that suggest entity IDs with name hints from the local cache.

Purpose: When a user tab-completes an entity ID argument (e.g., `pipelite deals get <TAB>`), the shell shows cached entity IDs with human-readable name hints like `abc123 -- Big Deal Corp`.     1. Update `Cargo.toml`: Change `clap_complete = "4.6"` to `clap_complete = { version = "4.6", features = ["unstable-dynamic"] }`.

    2. For each entity CLI arg file, add a candidate function that reads from cache and returns CompletionCandidate values. The pattern is the same for all entities:

    ```rust
    use clap_complete::engine::{ArgValueCandidates, CompletionCandidate};
    use crate::cache::CacheStore;

    fn {entity}_id_candidates() -> Vec<CompletionCandidate> {
        let cache = match CacheStore::new() {
            Ok(c) => c,
            Err(_) => return vec![],
        };
        let items: Vec<(String, String)> = cache
            .get(crate::cache::KEY_{ENTITY})
            .unwrap_or_default();

        items.into_iter()
            .map(|(id, name)| {
                CompletionCandidate::new(id)
                    .help(Some(name.into()))
            })
            .collect()
    }
    ```

    3. Wire the candidate function into every entity ID `#[arg]` attribute using `add = ArgValueCandidates::new({entity}_id_candidates)`:

    **src/cli/deals.rs**: Add `deal_id_candidates()`. Wire into DealsGetArgs.id, DealsUpdateArgs.id, DealsDeleteArgs.id:
    ```rust

    ```
