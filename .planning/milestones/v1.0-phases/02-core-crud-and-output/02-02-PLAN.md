1. Create src/cli/deals.rs with the full clap subcommand tree:
   - `DealsCommands` enum with variants: List(DealsListArgs), Get(DealsGetArgs), Create(DealsCreateArgs), Update(DealsUpdateArgs), Delete(DealsDeleteArgs)
   - Each variant gets `#[command(after_help = "Examples:\n  ...")]` with realistic examples.
   - `DealsListArgs`:
     - `--stage <id>` (Option<String>) — filter by stage
     - `--org <id>` (Option<String>) — filter by organization
     - `--owner <id>` (Option<String>) — filter by owner
     - `--limit <n>` (u64, default 50) — max results
     - `--offset <n>` (u64, default 0) — pagination offset
     - `--all` (bool) — auto-paginate up to 1000
     - `--fields <f1,f2>` (Option<Vec<String>>, value_delimiter=',') — select specific fields
     - `--expand <rel1,rel2>` (Option<Vec<String>>, value_delimiter=',') — expand relations
   - `DealsGetArgs`:
     - `id` positional (String) — deal ID
     - `--fields` and `--expand` same as list
   - `DealsCreateArgs`:
     - `--title <title>` (String, required) — deal title
     - `--stage <id>` (String, required) — stage ID
     - `--value <amount>` (Option<f64>) — deal value
     - `--org <id>` (Option<String>) — organization ID
     - `--person <id>` (Option<String>) — person ID
     - `--expected-close-date <date>` (Option<String>) — ISO date
     - `--notes <text>` (Option<String>) — notes
     - `--custom-field <key=value>` (Vec<String>, repeatable) — custom fields
     - `--stdin` (bool) — read JSON array from stdin for batch create
   - `DealsUpdateArgs`:
     - `id` positional (String) — deal ID
     - All create fields as optional (including --title and --stage)
     - No --stdin
   - `DealsDeleteArgs`:
     - `id` positional (String) — deal ID

2. Update src/cli/mod.rs:
   - Add `pub mod deals;`
   - Add `Deals(deals::DealsCommands)` variant to Commands enum with `#[command(subcommand, after_help = "...")]`
   - Import DealsCommands

3. Add CRUD methods to PipeliteClient in src/api/mod.rs:
   - Create a shared `async fn handle_response<T: DeserializeOwned>(&self, response: reqwest::Response) -> Result<T>` method that:
     - Checks status code
     - Maps 401/403 to CliError::Auth
     - Maps 404 to CliError::NotFound
     - Maps 422 to CliError::Validation (try to parse error body for detail)
     - Maps other errors to CliError::Api with status code
     - On success, deserializes JSON body
   - `pub async fn list_deals(&self, params: &DealsListParams) -> Result<ApiListResponse<Deal>>` — GET /api/v1/deals with query params via reqwest .query(). DealsListParams struct with stage, org, owner, limit, offset, expand as Option fields.
   - `pub async fn get_deal(&self, id: &str, expand: Option<&[String]>) -> Result<Deal>` — GET /api/v1/deals/:id
   - `pub async fn create_deal(&self, data: &DealCreate) -> Result<Deal>` — POST /api/v1/deals
   - `pub async fn update_deal(&self, id: &str, data: &DealUpdate) -> Result<Deal>` — PUT /api/v1/deals/:id
   - `pub async fn delete_deal(&self, id: &str) -> Result<()>` — DELETE /api/v1/deals/:id (handle 204 No Content)
   - `pub async fn batch_create_deals(&self, deals: &[DealCreate]) -> Result<Vec<Deal>>` — POST /api/v1/deals/batch
   - Add `DealsListParams` struct with `to_query_pairs(&self) -> Vec<(String, String)>` method for building query string. Use reqwest .query() with the pairs.

4. Update src/commands/mod.rs to add `pub mod deals;`

           DealsCommands::Get(args) => get::run(ctx, args).await,
           DealsCommands::Create(args) => create::run(ctx, args).await,

           DealsCommands::Delete(args) => delete::run(ctx, args).await,
       }
   }

   - Build DealsListParams from DealsListArgs
   - If --all flag: implement auto-pagination loop fetching batches of 100, capped at 1000 records. Print warning to stderr if total > 1000.
   - Otherwise: single API call with limit/offset
   - Convert Vec<Deal> to Vec<serde_json::Value> via serde_json::to_value
   - Get columns from deals_table_config().default_columns, or override with --fields if provided
