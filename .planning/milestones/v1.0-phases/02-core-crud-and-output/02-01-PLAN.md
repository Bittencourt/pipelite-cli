<task type="auto">
  <name>Task 2: Build generic output rendering layer (table, JSON, CSV, plain) with field selection, formatting, and color</name>
  <files>src/output/mod.rs, src/output/table.rs, src/output/json.rs, src/output/csv.rs, src/output/plain.rs, src/output/fields.rs, src/output/format.rs</files>
  <action>
1. Create src/output/fields.rs — field selection and extraction:
   - `pub fn extract_field(value: &serde_json::Value, path: &str) -> String` — traverse dot-notation paths (e.g., "custom_fields.industry"). Return empty string for missing fields. Format Value::String as-is, Value::Null as empty, numbers/bools as their string representation.
   - `pub fn filter_fields(value: &serde_json::Value, fields: &[String]) -> serde_json::Value` — returns a new Value::Object containing only the requested fields (for JSON output). Supports dot notation.
   - Unit tests: extract from nested objects, missing fields return empty, null fields return empty, dot notation traversal.

2. Create src/output/format.rs — value formatting for table display:
   - `pub fn format_value(key: &str, value: &serde_json::Value, color: bool) -> String` — format based on field name heuristics:
     - Fields ending in "_at" or "_date": parse ISO 8601 with chrono, display as relative time via chrono-humanize (e.g., "2h ago"). Fall back to raw string if parsing fails.
     - "value" field: format as currency with commas (e.g., 50000.0 -> "50,000"). No currency symbol (API doesn't specify currency).
     - All other fields: plain string representation.
   - `pub fn truncate_with_ellipsis(s: &str, max_width: usize) -> String` — truncate to max_width with "..." suffix if exceeds. Handle UTF-8 grapheme clusters correctly.
   - Unit tests: relative date formatting, currency formatting, truncation, fallback for unparseable dates.

3. Create src/output/json.rs — JSON output:
   - `pub fn render_list(items: &[serde_json::Value], fields: &Option<Vec<String>>) -> anyhow::Result<()>` — if fields provided, filter each item. Print as pretty JSON array to stdout.
   - `pub fn render_single(item: &serde_json::Value, fields: &Option<Vec<String>>) -> anyhow::Result<()>` — if fields provided, filter. Print as pretty JSON object to stdout.
   - Unit tests: verify valid JSON output, field filtering works.

4. Create src/output/csv.rs — CSV output:
   - `pub fn render_list(items: &[serde_json::Value], columns: &[String]) -> anyhow::Result<()>` — use csv::WriterBuilder to write header row + data rows to stdout. Extract values via extract_field. Handle embedded commas/quotes via csv crate.
   - Unit tests: header present, values correctly extracted, special characters escaped.

5. Create src/output/plain.rs — plain tab-separated output:
   - `pub fn render_list(items: &[serde_json::Value], columns: &[String]) -> anyhow::Result<()>` — write tab-separated values, no headers, no borders. One line per item.
   - Unit tests: no headers, tab-separated, one line per item.

6. Rewrite src/output/table.rs — table rendering with comfy-table:
   - `pub fn render_list(items: &[serde_json::Value], columns: &[String], color: bool, meta: Option<&PaginationMeta>) -> anyhow::Result<()>` — build comfy-table with:
     - ContentArrangement::Dynamic
     - Headers from columns, styled dim if color=true (use colored crate on header strings)
     - Values extracted via extract_field, formatted via format_value
     - Right-alignment on "value" column via CellAlignment::Right
     - UpperBoundary constraint on "title" column (Width::Fixed(40))
     - Truncation indicator "..."
     - If meta provided, print footer line: "Showing {offset+1}-{offset+count} of {total}"
   - `pub fn render_single(item: &serde_json::Value, columns: &[String], color: bool) -> anyhow::Result<()>` — key-value vertical display like `gh issue view`. Left column is field name (dimmed if color), right column is formatted value. Use simple padding alignment, not comfy-table.
   - When `--format table` is forced but stdout is not TTY, fall back to 120 column width.
   - Unit tests: verify table has correct row count, single renders key-value pairs.

7. Update src/output/mod.rs — orchestration:
   - Keep existing OutputFormat and detect_format.
   - Add `pub mod json; pub mod csv; pub mod plain; pub mod fields; pub mod format;`
   - Add dispatch functions:
     ```rust
     pub fn render_list(
         items: &[serde_json::Value],
         format: &OutputFormat,
         columns: &[String],
         fields: &Option<Vec<String>>,
         color: bool,
         meta: Option<&PaginationMeta>,
     ) -> anyhow::Result<()>
     ```
     Dispatches to the appropriate submodule. For JSON, pass fields for filtering. For table/csv/plain, use columns (or fields if provided to override columns).
   - Add `render_single` with similar dispatch.
   - Import PaginationMeta from api::models.

Note: All output functions write to stdout directly. Tests should capture output via writing to a Vec<u8> buffer or by testing internal formatting functions that return strings rather than printing. Structure internal helpers to return String/Vec<String> and have the public functions handle the final stdout write. This enables testability.
