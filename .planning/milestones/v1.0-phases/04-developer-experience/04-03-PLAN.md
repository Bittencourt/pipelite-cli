Tests to write:

1. **deals_create_missing_required_fields_lists_all**: Run `pipelite deals create` with piped empty stdin (non-TTY). Assert exit code 2 (not 1). Assert stderr contains "--title" AND "--stage" in a single error message. This verifies HEAD-02 (all missing fields at once).

4. **orgs_create_missing_name**: Run `pipelite orgs create` with piped stdin. Assert exit code 2. Assert stderr contains "--name".

5. **people_create_missing_both_names**: Run `pipelite people create` with piped stdin. Assert exit code 2. Assert stderr contains "--first-name" AND "--last-name".

6. **activities_create_missing_required**: Run `pipelite activities create` with piped stdin. Assert exit code 2. Assert stderr contains "--title" AND "--type".

7. **stages_create_missing_required**: Run `pipelite stages create` with piped stdin. Assert exit code 2. Assert stderr contains "--name" AND "--pipeline".

8. **pipelines_create_missing_name**: Run `pipelite pipelines create` with piped stdin. Assert exit code 2. Assert stderr contains "--name".

9. **stdin_and_flags_mutually_exclusive**: Run `pipelite deals create --stdin --title "X"` with piped JSON stdin. Assert failure with stderr containing "mutually exclusive" or similar.
