**CONTEXT AMENDMENTS applied (orchestrator, fact-driven from research — binding):**
1. **Purge = CLI fan-out** (no bulk endpoint exists server-side): paged list → per-record DELETE; loop breaks on an empty page (past-cap offsets return empty data + truthful total); bounded at offset 10,000.
2. **Purge non-TTY no-`--force` refusal = CliError::InvalidInput (exit 2)**, NOT Validation — deliberately stricter than the standard delete's exit 1 (which 11-01 kept for webhook delete).
3. **`--all` goes on trash list** (bounded fan-out, server offset cap 10,000 makes it safe); audit (11-03) gets NO --all.
4. **Zero-HTTP refusal covers the whole command**: the non-TTY refusal fires BEFORE the fan-out list GETs — type normalization happens first, then the gate, then any HTTP.
5. Per-item purge failures are **continue-on-error with an N ok / M failed summary** (amends RESEARCH Pattern 2's abort-on-first-403: a 403 mid-fan-out renders the trash hint per failed item via surface "trash" and counts as a failure; the loop continues per the orchestrator contract).

**Planner decisions pinned (agent's-discretion areas):**
- **Restore 403 hint key (P6): "general"** — zero new registration; wording "Your API key doesn't have permission for this action." is honest for owner-or-admin scope. Purge keeps "trash". A stub test asserts the restore hint is the general wording AND does not contain "purge".
- **Restore 404 re-wrap**: the server's 404 detail is preserved; the command layer appends the hint "The record is not in the trash — it may already be restored or purged, or never existed." (docs-command re-wrap precedent from Phase 9).
- **Table columns**: name, type, deleted_at, deleted_by, linked_parents. linked_parents cell = names joined ", " then truncate_with_ellipsis(80) (json keeps the full array). deleted_by cell = `deleted_by_label`: kind plus " (name <email>)" or " (workflow_name)" when present; bare kind for api_key/import/system/not_recorded/unknown_user.

- **No cache** for trash (never cached, per CONTEXT) — no KEY_TRASH, no invalidation.
- **Empty purge scope**: list returns 0 victims → "Trash is empty" stderr hint (quiet-suppressible), exit 0, no prompt, no deletes.
