6. **src/prompt.rs**: Create shared prompt module with these public functions:
   - `require_text(flag_value: &Option<String>, field_name: &str, prompt_label: &str, missing: &mut Vec<String>, no_input: bool) -> Result<Option<String>>`: Returns flag value if present, prompts with dialoguer Input if TTY and not no_input, otherwise pushes "--{field_name}" to missing and returns None.
   - `require_select(flag_value: &Option<String>, field_name: &str, prompt_label: &str, options: &[(String, String)], missing: &mut Vec<String>, no_input: bool) -> Result<Option<String>>`: Returns flag value if present, uses FuzzySelect with "name (id)" display format if TTY and not no_input, otherwise pushes to missing. Returns the ID (first tuple element).
   - `optional_text(flag_value: &Option<String>, prompt_label: &str, no_input: bool) -> Result<Option<String>>`: Returns flag value if present, prompts with "(optional, press Enter to skip)" suffix if TTY and not no_input, returns None on empty input or if headless.
   - `optional_number(flag_value: &Option<f64>, prompt_label: &str, no_input: bool) -> Result<Option<f64>>`: Same pattern for numeric fields.
   - `check_missing(missing: &[String], usage_hint: &str) -> Result<(), CliError>`: If non-empty, returns CliError::MissingInput with "Missing required flags: --x, --y" detail and the usage_hint.

   All prompt functions must check `std::io::stdin().is_terminal()` AND `!no_input` before calling dialoguer. This prevents panics.

7. **src/dry_run.rs**: Create dry-run rendering module:
   - `render_dry_run(method: &str, url: &str, body: &serde_json::Value, format: &OutputFormat, color: bool) -> Result<()>`: For Json format, output `{"dry_run": true, "method": ..., "url": ..., "body": ...}`. For other formats, print colored "METHOD URL" line then pretty-printed JSON body.
   - `render_dry_run_delete(entity: &str, id: &str, url: &str, format: &OutputFormat, color: bool) -> Result<()>`: For Json format, output structured JSON. For other formats, print "Would delete {entity} {id}".

8. **src/commands/completions.rs**: Create command handler:
   ```rust
   use clap::CommandFactory;
   use clap_complete::aot::generate;
   use crate::cli::Cli;
   use crate::cli::completions::CompletionsArgs;

   pub fn run(args: &CompletionsArgs) -> anyhow::Result<()> {
       let mut cmd = Cli::command();
       generate(args.shell, &mut cmd, "pipelite", &mut std::io::stdout());
       // Print install instructions on stderr
       let instruction = match args.shell {
           clap_complete::aot::Shell::Bash => "Add to ~/.bashrc:\n  source <(pipelite completions bash)",
           clap_complete::aot::Shell::Zsh => "Add to ~/.zshrc:\n  source <(pipelite completions zsh)",
           clap_complete::aot::Shell::Fish => "Run once:\n  pipelite completions fish > ~/.config/fish/completions/pipelite.fish",
           _ => "See your shell's documentation for completion installation.",
       };
       eprintln!("\n# Install instructions:\n# {}", instruction.replace('\n', "\n# "));
       Ok(())
   }
   ```
