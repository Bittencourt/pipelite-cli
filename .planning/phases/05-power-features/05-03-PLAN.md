<objective>
Wire the cache into interactive prompts so FuzzySelect dropdowns load options from cache first with API fallback.

Purpose: Make interactive prompts (pipeline selection, stage selection, org selection) feel instant when cache is warm by reading from local JSON files instead of making API calls. When cache is empty or expired, fall back to API and populate the cache for next time. This is the key user-facing benefit of the cache system.

Output: Cache-backed prompt helpers used by all create/update commands that show FuzzySelect dropdowns.
</objective>

  <name>Task 1: Add cache-through helpers to prompt module</name>
  <files>src/prompt.rs</files>
  <action>
    Add three async helper functions to `src/prompt.rs` that implement the cache-through pattern: try cache first, fall back to API on miss, populate cache on fetch.

    1. `pub async fn get_pipelines_cached(cache: Option<&CacheStore>, client: &PipeliteClient) -> Result<Vec<(String, String)>>`:
       - If cache is Some, try `cache.get::<Vec<(String, String)>>(KEY_PIPELINES)`.
       - If cache hit, return immediately.
       - On miss (or cache is None), fetch from API using `client.list_pipelines()` with auto-paginate (limit=100, loop until data.len() < limit).
       - Map response to `Vec<(String, String)>` as `(pipeline.id, pipeline.name)`.
       - If cache is Some, store result with `cache.set(KEY_PIPELINES, &items, TTL_PIPELINES)` (ignore set errors).
       - Return items.

    2. `pub async fn get_stages_cached(cache: Option<&CacheStore>, client: &PipeliteClient, pipeline_id: &str) -> Result<Vec<(String, String)>>`:
       - Cache key: `format!("stages_{}", pipeline_id)`.
       - Same cache-through pattern. Fetch via `client.list_stages()` with the pipeline_id.
       - Map to `(stage.id, stage.name)`.
       - Store with TTL_STAGES.

    3. `pub async fn get_orgs_cached(cache: Option<&CacheStore>, client: &PipeliteClient) -> Result<Vec<(String, String)>>`:
       - Cache key: KEY_ORGS.
       - Same pattern. Fetch via `client.list_orgs()`.
       - Map to `(org.id, org.name)`.
       - Store with TTL_ENTITY_LIST (orgs are entity lists, 5 min TTL).

    Import CacheStore, TTL constants, and KEY constants from `crate::cache`.
    Import PipeliteClient and list param types from `crate::api`.
